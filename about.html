프로그램 내용 및 문제점

원본 자바 프로그램(Ver 4.5.0)의 안내문을 웹용으로 정리했습니다.

Main Program

계산기

  • Rad·Degree, 순열(mPn), 조합(mCn), 계승(m!), 지수, 제곱근, 세제곱근, 역수, 몫, 나머지. 큰 수를 정확하게 처리
  • 일반용 sin, cos, tan, log, e, π
  • 과학용 논리연산(AND, OR, XOR), Shift 연산(<<, >>, >>>), 비트연산(&, |, ^, ∼)
  • 수학용 중복순열 mΠn, 중복조합 mHn, 전사함수 개수 mTn, 스털링 수 mSn, 벨 수 mBn, 자연수 분할 p(n)
  • 정수론용 오일러 함수 φ(n), 최소 원시근, 무리수의 연분수, 교란수 D(n), 카탈란 수, 감마함수 Γ(n)
  • 통계용 정규분포, χ²(n), Student t-분포, F-분포, 이항분포

정수론

  • 소인수분해, n!에서 소수 p의 지수(예: 35!의 끝자리 0의 개수), 큰 수의 GCD·LCM
  • 위수와 원시근 ordₙ(a) = min{k | aᵏ ≡ 1 (mod n)}, 최소 원시근, 원시근의 개수와 목록
  • 연분수 연분수 ↔ 분수, 소수·무리수·초월수(exp, πˣ, sin, cos, tan, log)를 연분수로
  • 이산대수 다항 합동식, 단항 계승·지수, 지수 합동식(Ind 이용 풀이), 르장드르 기호, 중국인 나머지 정리
  • 부정방정식 일차 부정방정식, 펠 방정식 x² − dy² = 1, x² + bxy + cy² = d

이산통계

  • 통계값, 모평균·모분산·분산비의 신뢰구간, 회귀직선·이차 회귀곡선, Wilcoxon 순위합·부호순위 검정
  • 통계표: 이항, 정규, χ², t, F, 기하, 초기하, 포아송, 감마 분포

이산·특수함수

  • 진법변환(36진법까지, 소수점 포함, 칸토어 표현), 지수·로그, 삼각·쌍곡함수와 역함수
  • 순열·조합, 스털링 수, 분할수, 카탈란 수, 벨 수, 교란수, 다항계수, 루크 다항식
  • Γ(n+1) = n·Γ(n) = n!, B(m, n) = Γ(m)Γ(n)/Γ(m+n), erf(x), 베셀 함수

행렬활용

  • 행렬 연산, 2×2 행렬로 복소수, 2×4 행렬로 사원수, n-벡터 연산과 부피, n-Simplex
  • LU·SVD 분해로 연립방정식과 최소제곱해
  • 고유분해로 대각화, QR 분해로 직교화, 이차형식의 표준화, 선형변환과 전이행렬
  • 행렬식, 역행렬, rank, pivot, 고유값·고유벡터, Binet 형태 수열(피보나치, 루카스, 펠, 페르마, 야콥스탈)

평면도형

  • 평면벡터, 삼각형의 오심, 직선의 방정식·교점·거리·각의 이등분선
  • 다각형의 넓이, 도형의 이동, 자취
  • 다항함수: 함수값, 조립제법, 접선·법선, 곡률, 사칙연산, 근, 극값, 적분, 넓이, 회전체 부피
  • 특수 다항식: 체비쇼프, 베르누이, 오일러, 라게르, 야코비, 페르마, 벨, 피보나치, 루카스, 펠 등

공간도형

  • 공간벡터 연산, 삼각형의 오심, 사면체의 외심
  • 직선과 평면의 방정식, 수선의 발, 교점·교선
  • 점·직선·평면·도형의 회전(점 P 중심, 축 u, 각 θ), 길이·넓이·부피·각

Sub Program

  • Calendar 두 달치 달력
  • Puzzle 5×5 그림 맞추기
  • Graph 평면곡선 1·2·3(사이클로이드, 장미곡선, 리사주, 나선, 리마송, 포락선, 신개선·축폐선 등), 그래프 교점, 정함수 개형, 공간곡선, 아핀변환, 문제풀이 예(정수론·행렬·벡터공간 27개 항목)

문제점 (원본 안내문)

  • 컴퓨터는 소수점 아래 자릿수에 제한이 있고, 1/3·√5 같은 수를 근삿값으로 표현한다.
  • 펠 방정식은 해의 범위를 10000까지로 했으며, 범위를 10배 늘리면 시간이 더 걸린다.
  • 소수점이 있는 m진법 → 10진법 변환은 순환하는 경우가 있어 소수점 아래 20자리까지 표시한다.
  • 실수 지수는 배정도(double) 범위에서 계산하므로 정수부가 크면 소수부의 정확성이 떨어진다.
  • m, n이 크면 Γ(m)은 매우 커지고 B(m, n)은 매우 작아지므로 log Γ, log B로 구한다.
  • 3D 그래프는 입체감이 부족하다.

웹 버전에서 달라진 점

  • 설치 없이 브라우저(PC·태블릿·휴대폰)에서 바로 실행됩니다.
  • 정수 계산은 JavaScript BigInt로 하여 자릿수 제한 없이 정확합니다.
  • 거듭제곱 나머지는 반복 제곱법(modPow)으로 계산하여 큰 법에서도 빠릅니다.
  • 퍼즐은 항상 풀 수 있는 배치로 섞고, 완성하면 자동으로 알려 줍니다.
  • 입력은 식을 그대로 씁니다 (예: x^3 + 2x^2 - 1 ≡ 7 (mod 23), 2sqrt(3)/5, 30°). 입력방법의 예시를 누르면 바로 계산됩니다.
  • 결과를 분수, a√b, π 꼴로 함께 보여 줍니다.
  • 그래프는 끌어서 이동하고 확대할 수 있으며, 3D 그래프는 마우스로 돌려 볼 수 있습니다 (원본의 “3D 입체감 부족” 해결).
  • 펠 방정식은 연분수로 최소해를 바로 구하므로 x² − 61y² = 1 처럼 해가 아주 큰 경우도 즉시 나옵니다 (원본은 범위 10000 제한).
  • 소인수분해는 폴라드 로 방법을 써서 20자리 가까운 수도 금방 분해합니다.
